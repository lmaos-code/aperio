# Glossary

## MCP
**Model Context Protocol** - A protocol for AI agents to interact with external tools and data sources.

## OIDC
**OpenID Connect** - An authentication layer on top of OAuth 2.0.

## PKCE
**Proof Key for Code Exchange** - A security extension to OAuth 2.0 for public clients.

## JWT
**JSON Web Token** - A compact, URL-safe means of representing claims.

## PVC
**Persistent Volume Claim** - A request for storage in Kubernetes.

## Obsidian Sync
Obsidian's built-in end-to-end encrypted synchronization service.
